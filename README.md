# local_storage_exercise

local_storage_exercise is a small exercise designed to explain what Local Storage is and how to use it.

## Features

* Store data – Save data in Local Storage
* Retrieve data – Read stored data from Local Storage
* Remove data – Delete data from Local Storage
* Persistent data – Keep data available after reloading the page

## Technologies

* HTML
* CSS
* JavaScript
